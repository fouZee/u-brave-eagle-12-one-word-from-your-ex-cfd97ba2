Temporary — the one word my ex would use to describe me. This program writes
exactly that word to `/output/entry.txt`, nothing else — no sentence, no
explanation, no punctuation tricks. One word: the whole relationship summed
up as a placeholder. You were never the plan, just the "for now".

## Run it

```sh
node main.ts
```

This writes `Temporary` (9 characters) to `/output/entry.txt`.
